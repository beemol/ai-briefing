# 📖 Глоссарий сокращений — AI-ассистент по лизингу

> **Для кого:** этот файл читает руководитель компании (CEO).
> **Зачем:** мы учим AI-ассистента понимать внутренние сокращения и коды, которые встречаются в Bitrix24 и Power BI. Часть таблиц уже заполнена автоматически из систем. Нужно, чтобы вы **дописали колонку «Что значит»** — своими словами, как вы это называете в команде.
> **Как это работает:** после заполнения этот файл станет «словарём» ассистента — он будет правильно понимать, что такое «Дожим КМ», «Отказ СБ», «Воронка Лизинг» и т.д.

> **CEO:** подтвердите, пожалуйста, что `TS_ISSUED` = «ТС выдано» (старое название), или напишите, что это значит.

## 3. Сокращения в названиях

> **CEO:** напишите расшифровку своими словами. Часть — наши предположения (отмечены «?»), подтвердите или исправьте.

| Сокращение | Где встречается | Расшифровка (заполнить / подтвердить) |
|---|---|---|
| КМ | Одобрен КМ, Дожим КМ, Отказ КМ, Комментарий КМ | предположение: клиентский менеджер |
| СБ | Отказ СБ, Заключение руководителя СБ | предположение: служба безопасности |
| РОП | таблицы «КП и Доки по РОП», колонка РОП | предположение: руководитель отдела продаж |
| СОП | колонка СОП, поле ufCrm31Sop | предположение: сотрудник отдела продаж ? |
| МОП | таблица «КП и Доки по МОП» | ? |
| БУ / Б/У | Лист ожидания Б/У, Пересмотр БУ, Спец. условия для БУ | предположение: б/у = бывший в употреблении (авто) ? |
| АТИ | Код АТИ, Перевозчики АТИ, АТИ (звёзды) | предположение: реестр автоперевозчиков АТИ |
| СТС | СТС подтверждены | свидетельство о регистрации ТС |
| ТС | Тип ТС, Дата выдачи ТС, объект лизинга | транспортное средство |
| ПВ | Первоначальный взнос, «перевели ПВ в 10» | предположение: первоначальный взнос |
| ИНН | ИНН лизингополучателя | идентификационный номер налогоплательщика |
| ЮЛ / ИП / ООО | Наличие ЮЛ, срок регистрации ООО или ИП | юридическое лицо / индивидуальный предприниматель / ООО |
| КП | КП отправлено, «КП и Доки по…» | коммерческое предложение |
| ОТК | Неполная проверка базы ОТК | отдел технического контроля ? |
| ГП | Не занимается ГП | грузоперевозки ? |
| НДС | Без НДС, С НДС | налог на добавленную стоимость |
| ЗУП | таблица «ЗУП» | 1С:Зарплата и управление персоналом ? |
| 1С | «База перевозчиков 1С (Факт)» | система 1С:Предприятие |
| UTM | UTM_SOURCE, UTM_CAMPAIGN | метки рекламных кампаний |
| Скоринг | «СКОРИНГ», результат аналитики | оценка рисков клиента |
| Бенефициар | поля [Бенефициар] | конечный владелец бизнеса |
| Лизингополучатель | ИНН лизингополучателя | тот, кто берёт технику в лизинг |
| Поручитель | Комментарий по Поручителю | гарант по сделке |
| ГРИДЫ | таблица «…(ГРИДЫ)» | ? |
| Суррогатный ключ | колонка «Суррогатный ключ…» | технический ключ связи (не бизнес-термин) |
