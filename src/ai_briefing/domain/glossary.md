# Глоссарий

## Метрики

| Метрика | Определение |
|---|---|
| Конверсия | % последовательных переходов между стадиями воронки |
| Эффективность менеджера | Кол-во подписаний — главный KPI менеджера по продажам |
| Выполнение плана | План по документам — расчётный, зависит от числа отработанных недель; ориентир для РОПа, метрика устаревшая |
| КС | Этап собеседования с Клиентским Сервисом (ответственные — клиентские менеджеры) |
